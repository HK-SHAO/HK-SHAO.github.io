## 做过的事

**字节跳动 · AI 生视频工作流平台（Owner）。** 从水平扩容与生产集群建设做起，打通 Go 服务端链路，把玩法搭建与运营从手工流程做成规模化落地的系统，并配上持续观测。这套基础设施直接支撑 400 多个创意特效玩法上线，每月生产 30 万条以上视频。

**腾讯 · 智能体系统与平台（Owner）。** 从 0 到 1 自研的多用户多会话 Agentic AI 产品，兼容 MCP 等工具调用，覆盖前后端与 API 服务。相比固定的流程编排，它用更自由的方式完成复杂任务。我搭建整体架构与前后端基建，负责 Agent 核心的上下文、规划、ReAct 与工具调用兼容，以及仓库规范、构建机与自动化发版流水线。10 位以上贡献者，1000 次以上提交。落地场景包括 AI 数据科学与旅行助手，我也以讲师身份分享过平台架构与落地实践。

**腾讯 · 多智能体工作流平台（Owner）。** 从 0 到 1 自研的流式多 Agent 编排 PaaS，对外提供兼容 OpenAI 的接口，节点涵盖智能对话、消息链表、远程调用、数据库与 CodeBox。前端以 Node 与 Edge 为交互理念做节点编排，核心是前向执行的节点引擎与执行流转换器。落地 100 多个流水线。

**腾讯 · 大模型评测平台（Owner）。** 从 0 到 1 自研的 LLM 评测与观测平台，用 SvelteKit 与 ECharts 做表单与可视化，后端是 MongoDB 加 Redis 的评测机与触发器服务。用它观察模型在特定任务上的性能随微调与超参变化，给算法侧提供可视化对比。
