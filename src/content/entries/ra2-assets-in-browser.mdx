《红色警戒 2》的安装目录是一堆私有格式：MIX 归档、256 色调色板、voxel 模型、帧动画、地图地块、语音库。它们都是二十多年前为 Windows 写的，而我想在浏览器里把它们摊开看。

## 两种运行形态

本地版是 Windows 上的 Web 应用。回环地址上跑一个 FastAPI 服务，浏览器只当界面。调用链是：

```text
只读游戏目录
  → MIX / 格式解析层
  → SQLite 索引与 RULES/ART/CSF 语义目录
  → FastAPI（127.0.0.1:46120）
  → React 界面
          ↘ 派生缓存
```

界面用用户机器上已有的浏览器，不嵌 Electron、Chromium 或 WebView，运行时不需要 Node。

离线网页包不跑 Python、FastAPI 或 SQLite。构建阶段把允许公开的语义目录与派生媒体转成只读文件，前端静态适配器实现同一套查询接口的子集。所以两种形态共用一份 React 界面。

## 格式层

| 格式 | 能做什么 |
| --- | --- |
| MIX / MMX / YRO | 经典与 RA2/TS 哈希、Blowfish 索引、嵌套归档、按区段读取 |
| PAL / VPL | 调色板与亮度层、网格预览、体素着色 |
| SHP | 压缩 0 到 3、透明索引、逐帧预览、阴影配对、动画序列 |
| VXL / HVA | 体素列与部件矩阵、八向组合、WebGL 三维场景、HVA 时间轴 |
| TMP | 菱形地块、深度与附加层、逐地块预览 |
| INI / CSF / TXT | 编码探测、结构解析、简繁本地化、全文检索 |
| WAV / AUD / IDX+BAG | PCM、IMA、Westwood 解码，按片段播放与导出 |
| VQA / BIK | 索引与按需转码 |

解析器对归档范围、递归深度、条目数、文本大小、图像像素、体素数和媒体输出都设了上限。单项损坏只产生一条可诊断的错误，不会把整次扫描拖垮。扫描结果原子替换，上一版可用索引留着，避免半成品覆盖。

## 只读是硬约束

游戏目录只读，任何流程都不运行其中的程序。普通浏览直接读松散文件或 MIX 区段，不永久复制成员；只有显式 `extract` 才产生原始副本。派生缓存的键包含来源、扫描修订、资产 ID、渲染参数和解析器版本，来源重扫或算法改了就不会命中旧结果。扫描器排除掉派生目录，防止自己的产物被当成游戏输入。

## 界面

全局搜索支持简繁中文、拼音与模糊匹配，`Ctrl+K` 随时唤起。盟军、苏军、尤里按玩家色着色，卡片、详情与动画保持一致。单位动画按主体、建造与运转状态分组，超级武器分阶段播放。音频进度条可以拖动跳转，视频自动取封面。

离线包解压即用，能直接浏览 559 个单位与 3348 个声音。
