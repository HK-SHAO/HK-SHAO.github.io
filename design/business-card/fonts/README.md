# Sarasa UI SC

These WOFF2 Latin subsets are derived from the hinted Sarasa UI SC faces in
[Sarasa Gothic v1.0.37](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.37).
They are licensed under the SIL Open Font License 1.1. [OFL.txt](OFL.txt) is the
[unmodified license from the release tag](https://raw.githubusercontent.com/be5invis/Sarasa-Gothic/v1.0.37/LICENSE).

| File           | CSS weight | SuperTTC index | PostScript name       |
| -------------- | ---------: | -------------: | --------------------- |
| regular.woff2  |        400 |            199 | Sarasa-UI-SC-Regular  |
| semibold.woff2 |        600 |            295 | Sarasa-UI-SC-SemiBold |
| bold.woff2     |        700 |            391 | Sarasa-UI-SC-Bold     |

FontTools 4.68.0 kept the source glyphs in U+0020–007E, U+00A0–00FF,
U+2000–206F, U+20AC, U+2122 and U+2212. The subset retains applicable OpenType
layout features, hinting, original font names and copyright metadata. The
upstream license reserves the name “Source”. The retained face names use
“Sarasa UI SC”.
