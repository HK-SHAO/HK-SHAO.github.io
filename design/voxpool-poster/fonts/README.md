# Sarasa UI SC

These hinted WOFF2 subsets are derived from
[Sarasa Gothic v1.0.37](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.37).
[OFL.txt](OFL.txt) is the SIL Open Font License 1.1
[from that release](https://raw.githubusercontent.com/be5invis/Sarasa-Gothic/v1.0.37/LICENSE).

| File           | CSS weight | SuperTTC index | PostScript name       |
| -------------- | ---------: | -------------: | --------------------- |
| regular.woff2  |        400 |            199 | Sarasa-UI-SC-Regular  |
| semibold.woff2 |        600 |            295 | Sarasa-UI-SC-SemiBold |

The subsets include Latin-1, available common Latin and CJK punctuation, and
Han characters for the VOXPOOL poster copy. FontTools 4.68.0 retained the
applicable OpenType features, hinting, font names and copyright metadata.
The upstream license reserves the name “Source”. The retained face names use
“Sarasa UI SC”.
